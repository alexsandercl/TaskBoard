# TaskBoard

Gerenciador de tarefas feito com HTML, CSS, JavaScript e Bootstrap 5. Não usa back end: os dados ficam salvos no `localStorage` do navegador.

## Funcionalidades
- Adicionar, editar, excluir e concluir tarefas
- Categoria, prioridade, prazo e observações em cada tarefa
- Subtarefas (checklist) dentro de cada tarefa
- Aviso de tarefas atrasadas
- Busca por texto e filtros por categoria e status
- Ordenação por prioridade, prazo ou mais recentes
- Resumo com total, pendentes, atrasadas, pendentes por categoria e barra de progresso
- Desfazer exclusão (inclusive ao limpar as concluídas)
- Modo escuro

## Como executar
Abra o arquivo `index.html` no navegador

## Tecnologias
HTML5, CSS3, JavaScript (ES6), Bootstrap 5.3
